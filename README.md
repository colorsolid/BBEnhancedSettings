
# BBEnhancedSettingsGUI
Change default settings of Bloodborne Enhanced mod for new characters.



## Compile

Compile with dotnet

```bash
  dotnet build --configuration Release BBEnhancedSettingsGUI.sln
```
or open BBEnhancedSettingsGUI.sln in Visual Studio.

Includes JKAnderson's SoulsFormats https://github.com/JKAnderson/SoulsFormats
